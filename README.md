# Canvas Player

Музыкальный плеер для [CanvasTTY](https://github.com/howdeploy/CanvasTTY),
который открывает интерфейс [music.deploychan.webcam](https://music.deploychan.webcam)
в карточке общего канваса рядом с терминалами и браузером.

## Установка

1. В CanvasTTY откройте **Настройки → Плагины**.
2. Вставьте `https://github.com/teo-nex/canvastty-player`.
3. Нажмите **Проверить → Установить**.
4. У плагина **Canvas Player** нажмите **Открыть**.

Переключатель **Включить / Выключить** управляет плагином. Выключение закрывает
его поверхность и останавливает музыку. Плитку запуска можно добавить в
**Оформление → Состав HOME**.

## Возможности

- Исходный интерфейс, плейлисты, трек-листы, обложки и варианты оформления.
- Воспроизведение, пауза, переключение треков, перемотка и громкость.
- Сохранение громкости в изолированном хранилище CanvasTTY.
- Полный плеер на общем канвасе и необязательный виджет HOME.
- Перемещение и изменение размера средствами карточек CanvasTTY.

Плеер использует Electron самой CanvasTTY. Отдельная установка Electron,
нативные службы и хуки агентов не нужны.

## Сеть и ограничения

Аудио и изображения загружаются с исходного сайта по HTTPS. Аудиофайлы
не включены в репозиторий. Для музыки нужен интернет, доступность треков
зависит от исходного сайта.

Интерфейс и каталог — снимок от **25 октября 2026 года**. Изменения исходного
сайта не появляются автоматически. Анализатор спектра отключён: аудиосервер
не разрешает CORS, а подключение такого потока к Web Audio может заглушить звук.
Воспроизведение использует прямой выход `<audio>`. Ограничения sandbox и CSP
CanvasTTY сохранены.

Разрешения: **network** для аудио и изображений, **storage** для громкости.
Плагин не объявляет hooks или services.

## Проверка

Версия 1.1.0 переводит полный плеер из отдельного окна в `canvas-app`.
Проверка этой версии в текущей CanvasTTY выполняется отдельно от проверки
статического пакета. Спектральный анализ остаётся отключён.

```sh
python3 tools/verify.py
node --check host.js
node --check launcher.js
```

## Обновление снимка

```sh
python3 tools/build.py
python3 tools/verify.py
```

Нужен только Python 3. Сборщик скачивает публичные статические ресурсы,
переносит inline bootstrap-код Next.js во внешние файлы и заменяет пути
аудио/изображений на HTTPS. При изменении реализации Web Audio сборка
останавливается для ручного пересмотра адаптации. ZIP создаётся локально.

`PROVENANCE.json` содержит источник, дату и SHA-256 исходных и адаптированных
ресурсов. Авторство исходного плеера, музыки и изображений сохраняется;
интеграция не заявляет на них права и не перелицензирует их.
