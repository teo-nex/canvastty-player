# Системные рамки для карточек плагинов

Патч изменяет renderer CanvasTTY 1.8.2, исходный тег `v1.8.2-test.2`
(`1e0fb1e0cbf66abaf4d30a043720cb016361ca9f`).
Он расширяет штатное оформление терминалов на canvas-app, включая Canvas Player.
Настройки рамки и детализации передаются из WorkspaceCanvas; пиксельные рамки
используют тот же Canvas2DSkinView и геометрию проёма. Пользовательский CSS
остаётся ограниченным карточкой. Маскоты исключены.

Пакет плеера не может менять DOM родительского приложения из sandbox iframe;
поэтому этот патч устанавливается на стороне host, отдельно от плагина.
Это локальное изменение, не официальный релиз CanvasTTY. При замене host
официальным обновлением поддержку рамок нужно проверить заново.

В чистом checkout CanvasTTY соответствующего тега:

```sh
git am /path/to/canvastty-1.8.2-plugin-frames.patch
```

Далее используйте обычную сборку CanvasTTY из её документации. Применять ASAR
из другой версии или менять архив работающего процесса нельзя: Electron
проверяет целостность и кеширует содержимое. Сохраните предыдущую сборку.
Перезапуск host закрывает текущие терминальные процессы.

Проверка 25.10.2026, macOS arm64: 31 профильный и 12 связанных тестов, web typecheck,
production renderer build, codesign verification локальной сборки. В отдельном
профиле настоящего клиента видна Gothic Eclipse / Detailed; позиция трека
выросла с 0:00 до 0:15. Выбор Glass и возврат Gothic сохранены через настройки.
Нативные компоненты, main/preload, sandbox, CSP и Electron fuses сохранены.
Приёмка в основном профиле ожидает разрешённого перезапуска.
